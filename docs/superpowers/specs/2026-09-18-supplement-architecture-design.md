# 总体架构与持续补充（用户已确认）

取代上一版双视图设计。只显示 Visio 第一页总体架构，明确 1 个总控和 3 个专业 Agent；总控当前使用固定路由，验证解释当前仅程序校验。真实后端事件驱动所有已接入节点和实际调用连线，未调用能力不得假亮。

任务输入区展示可编辑的“当前任务描述”。独立补充区常驻，列出当前追问、输入框、每轮补充、修改前后差异和处理方式。提交补充创建新输入版本，使旧确认和旧结果失效；用户核对新版本后才计算。最初输入、补充原话、历次描述和参数来源永久保存在本地任务历史中，刷新/重启可恢复。

受控合并：明确的单值频率/距离补充可以替换旧参数；只替换经定位的数值单位片段，保留其他上下文。同步已有手工参数，记录差异。可选本机 LLM 输出结构化建议，数值仍由程序从用户原话抽取、核验，不能自由编造全文。歧义、未支持的表达先追问；未解决问题阻止确认。下一轮明确同一参数可解决对应问题，用户也可显式撤回未应用的补充。其他未决问题继续保留。模式及降级原因显示。

不改变专业计算底座、不自动启动模型、不提交或发布 Git。保持事务原子性、CAS、幂等、历史只读和来源链。
