# 演示视频录制提纲

状态：待用户录制，目前没有视频文件或播放链接。建议 1080p、2–3 分钟，录制工作台和必要的启动过程。

| 时段 | 操作与画面 | 需要说明的事实 |
| --- | --- | --- |
| 0:00–0:20 | 双击根目录“启动.cmd”，等待打开工作台 | 模型与网页服务就绪后再开始业务演示；首次模型加载可剪辑等待时间。 |
| 0:20–0:45 | 选择本机 Qwen，输入“按自由空间基准计算，频率 2 GHz，求路径损耗” | 查看缺失距离与需求解析来源；录制前确认模型可正常响应。 |
| 0:45–1:10 | 补充“距离 1 km”，展示参数、来源与模型假设 | 当前版本由用户核对确认，不能跳过确认直接计算。 |
| 1:10–1:40 | 确认并计算，展开计算与审查节点 | 结果约 98.420600 dB；展示实际角色模式、硬校验、审查结果与调度记录。 |
| 1:40–2:10 | 补充“频率改为 3 GHz” | 展示旧确认与结果失效，重新确认后约 101.942425 dB。 |
| 2:10–2:40 | 查看历史、导出 JSON，回到架构单视图 | 历史只读；当前为受控自由空间原型，海面/散射及候选优化未实现。 |

如果页面显示模型超时或 deterministic_fallback，录制应如实标明降级。启动就绪只说明服务可连接，不证明每次推理都能在时限内完成。建议先完成一次完整试跑，再录正式演示。

## 录制完成后

提供 MP4 文件或已上传的视频播放链接即可接入首页。推荐用外部播放链接加封面，避免将大视频反复提交到 Git 历史。封面可放在 `docs/demo/demo-cover.png`；将根 README“演示视频”章节的“待录制”替换为真实链接，附录制日期与对应代码版本。

不提前创建不可播放的占位链接，也不把 Visio 目标设计当作已完成能力介绍。
