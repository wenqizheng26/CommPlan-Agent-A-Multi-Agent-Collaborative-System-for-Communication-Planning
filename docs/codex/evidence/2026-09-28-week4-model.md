# 第 4 周：抽取与追问的真实模型评测（2026-09-28）

- 目的：在本机 9B 上核对资料抽取（草稿）与换电台、换站点的追问。
- 脚本：`scripts/eval_week4.py`。在知识目录的临时副本上运行，草稿与审核不写回仓库；每次输出一个新文件，不覆盖旧记录。
- 模型：`qwen35-9b-q4`，温度 0，GPU（Vulkan）；向量服务只用 CPU。
- 用例：
  - 抽取 5 例：XX-300 设备、XX-300 的 EIRP 公式、只选前言（应无草稿）、只选规格表抽公式（应无草稿）、XX-100 设备（库里已有，应不可入库）。

    - 7 条应合并：换电台、换站点、两项一起换。
    - 7 条应反问或不处理：没说换哪一端、说法犹豫、已在用、库里没有、非换用的提问。
    - XX-300 两条：审核前应反问“只有未审核的草稿”，审核后应合并。
  - 端到端 1 条：新建 → 确认 → “换 XX-200 呢” → 确认，余量应为 5.93 dB → 20.93 dB。
