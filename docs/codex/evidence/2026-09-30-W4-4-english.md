# W4-4：英文需求与模型核对

## 实现

- 支持英文载频、距离、发射功率、收发天线增益、馈线损耗、接收门限、预留余量及四张补充卡的参数标签；大小写不敏感，单位换算沿用原受控转换器。
- 英文 calculate/compute/find/determine 目标与 free-space reference/model、single knife-edge、smooth sea two-ray 条件从原文解析；模型引用仍必须逐字来自英文原文。
- 保留输入来源的原始数值、单位与 Unicode 位置，不用模型翻译后的数值替换原文。
- 英文明确目标在需求 Agent 内扩展为登记卡的中文标题后检索，仍要求正常候选和正词项分数；空结果或零分不能确认。没有修改检索服务、术语表或 W4-2 评测查询。
- 否定、未知、近似、缺单位、冲突值不自动选值；带宽不变成载频，天线高度不变成距离。实际海面传播、双程雷达仍超出已支持范围。
- 英文数值补充可更新任务版本，原确认与结果失效。支持明确英文换电台动词；站点和设备名称仍使用已登记名称，不凭英文称呼创造记录。
- 模型候选资料附参数描述与单位，数量表附逐字上下文，新增两个适用条件进入约束解码 schema。
