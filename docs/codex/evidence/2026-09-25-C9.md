# C9：两张几何卡与假设值（2026-09-25）

工作区 `CommPlan-Agent-M1-codex`，分支 `codex/m1-week2`。本任务只注册和验证公式卡；需求解析、计划流程及页面提问未接入这些值。

## 实现与依据

- `radio_horizon` 为表达式卡 `4.12*(sqrt(antenna1_m)+sqrt(antenna2_m))`，两端天线离地高度以 m 输入，结果为 km。系数 4.12 是由两端各自 `sqrt(2kRh)` 在 `k=4/3`、`R≈6371 km` 下舍入得出；[ITU-R 手册 Part 1 §3.3](https://www.itu.int/dms_pub/itu-r/opb/hdb/R-HDB-54-2009-OAS-PDF-E.pdf) 给出标准大气中约 4/3 的 k 因子。此卡不含地形遮挡或菲涅耳区余隙。
- `slant_range_wgs84` 为白名单程序工具卡，按 WGS84 经纬高转换 ECEF，再求两端天线相位中心的弦长。WGS84 `a=6378137 m`、`f=1/298.257223563`。地面高程与天线离地高度相加时，地面高程必须已用 WGS84 椭球高；其他高程基准需先转换。[EPSG Guidance Note 7 的 GDAL 镜像](https://gdal.org/en/stable/proj_list/guid7.html) §2.2.1 给出转换公式，§2.3.2 给出 WGS84 公开算例；[NGA WGS84 页面](https://earth-info.nga.mil/?action=wgs84&dir=wgs84)说明该参考框架。
- EPSG 算例：纬度 53°48′33.82″ N、经度 2°07′46.38″ E、椭球高 73.0 m，文献列出的 X/Y/Z 为 3,771,793.97 / 140,253.34 / 5,124,304.35 m。实现值为 3,771,793.967642 / 140,253.341900 / 5,124,304.349351 m，三轴误差均小于 0.01 m。
- 独立复算在 `planning/services/reference_models.py` 用径向量与经度差的弦长恒等式，不调用 ECEF 实现；测试的两条卡片算例均在规定容差内。`formula_rag/tools.py` 的源码 SHA256 注入加载后的程序工具卡，因此卡片哈希与知识快照随实现文件字节变化。公式页遇到程序工具卡显示算法与出处，不显示表达式。
- `received_power` 的 `tx_loss_db`、`rx_loss_db` 假设值各 2 dB，`extra_loss_db` 为 0 dB；`link_margin.reserve_db` 为 0 dB。每项都有单位与说明，目录校验拒绝单位不符、越界或空说明。假设值目前不自动代入，避免在 A2/H3 接入前绕过确认。
- 假设值说明进入检索文档后，旧案例 `link_margin_missing_budget` 的前三个直接检索命中已包含 FSPL、接收功率和链路余量三张卡，故不再触发“补加上游公式”的条件性 `PLAN_DEPENDENCY` 诊断。36 条确定性案例只这一条的诊断集合改变；参数、目标、状态与提问合同未变。将该案例预期改为只要求 `MISSING_INPUT`，保留诊断本身的真实语义。
