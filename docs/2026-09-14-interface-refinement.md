# 自动识别、表格文本输入与公式展示调整

日期：2026-09-14。按本次对话已确认范围实施。

## 用户确认的范围

- 本次公式集合展示公开标准和文献。用户后续明确“表是给你参考的而不是计入系统，少说了就问用户让他再次输入”。因此已从运行公式库删除表格来源和备注，取消原表页面/API；保留开发参考副本与独立复算记录。不读取参考表补值。
- 数学表达式使用本地 LaTeX 渲染。计算目标和传播条件默认自动识别；手动纠正折叠为可选项；补充参数采用短标签、单位和提示说明。
- 公式集合单独折叠在页面下方。结果公式后的链接展开集合并定位、高亮相应卡片；卡片可返回结果，保留输入。
- 支持粘贴“参数（单位）数值”的多行文本和多个待求量。缺项、单位歧义、缺少适用模型时明确追问，不拿参考值或模型生成值填空。

## 实现与边界

模型返回候选 ID、计算目标/条件及连续原文依据。程序验证枚举、证据位置和条件规则；手动指定和输入中已有的明确目标优先。岸海、视距等词不能单独使自由空间模型适用。模型建议不会改变程序提取的数值，也不能新增计算公式。

LaTeX 从实际计算表达式的 AST 生成，符号表映射到输入单位。KaTeX 0.18.7 的脚本、字体、许可和文件校验和保存在项目内，页面不依赖 CDN。

公开公式新增热噪声谱密度、由 Eb/N0 和比特率计算接收门限，使接收电平与余量可按依赖顺序复算。噪声谱密度或参考温度必须明确输入，不默认使用 −174 dBm/Hz。天线增益需明确 dBi/dBd，Eb/N0 需明确 dB。漂移损耗是否已纳入额外损耗/预留量，含义不明时追问。

原表的多普勒损耗表达式没有纳入已审核公式。多普勒频移与多普勒损耗是不同输出；缺少波形、补偿策略和损耗模型时，系统说明不能计算该项，并保留可独立计算的其他结果。

结果保存由本机服务写入 `outputs/`。浏览器只提交本次计算记录 ID，不提交最终数值或文件路径。保存文件保留计算精度、公式版本、输入证据、模型解释和缺项信息。
