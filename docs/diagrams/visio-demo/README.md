## 与当前实现的差异

图稿描述 Demo 目标设计，不用于证明全部能力已经实现。

| 图中设计 | 当前实现（2026-09-21） |
| --- | --- |
| 总控调用共享 LLM | 主控为程序策略 bounded_policy，没有自主 LLM 总控。 |
| LLM 组织多步骤计划 | 当前计算建议只允许确认版本的单步 fspl_ghz。 |
| 审查阶段独立 RAG 检索、生成解释建议 | 当前复用已有事实进行结构化审查，报告正文由程序生成。 |
| 传输链路损耗模型统一接口 | 当前只支持明确自由空间假设的单链路损耗。 |
| 共享 RAG 与专业知识库 | 当前规划入口使用词项检索与版本化公式卡；不是完整通信知识库。 |
| 异常回退与重试 | 当前每版本最多计算两次；只有受控暂时故障与审查重算可以进入限定路径。 |

业务源码及最新工程交接决定已实现范围。后续修改图稿时，应在 Visio 中保存源文件并重新导出两张 PNG，保持源图与预览一致。
