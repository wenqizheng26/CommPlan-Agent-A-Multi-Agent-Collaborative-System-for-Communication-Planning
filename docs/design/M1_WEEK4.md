| 资料抽取与审核 | 工作台加“资料”页。流程：选文档章节 → 模型抽取站点、设备或公式草稿 → 每个字段旁显示原文摘录与程序核对结果（公式另核对算例）→ 填审核人后“通过”或“驳回”。通过即写入仓库里的库，驳回留下记录。未审核的草稿不能参与计算 |

| 连续追问 | 支持换电台、换站点（“换 XX-200 呢”“B 站换成 C 站呢”）。没说清换哪一端、或说法含糊时反问，不改输入。每次追问产生新版本，重新确认后计算 |
| 版本对比 | 结果下方加一行，只和上一版（最近一次追问之前的结果）对比 |
| 一键启动 | 父目录放 `启动 CommPlan.cmd` / `关闭 CommPlan.cmd`（不在 Git 内），仓库里放 `停止服务.cmd`。端口上是旧版工作台时，停掉后启动当前版本；已安装 Chrome 时用 Chrome 打开 |

| 模型切换 | 在设置里选模型，点“切换”：后台停掉旧模型、加载新模型，显示加载中与已等待时间。计算中不能切换 |

| 调研 | 第 4 周完成后再做：网上查通信公式与应用场景，方向为点对点链路、覆盖与组网、设备选型、特定场景。逐条标“现在能算 / 只缺公式卡 / 要加功能”，用户挑选后再做 |
